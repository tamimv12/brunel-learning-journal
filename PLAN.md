# 12-Week Pre-Brunel Foundation Plan

**Period:** 16 Oct 2026 → Jan 2027 (until Brunel teaching starts 25 Jan 2027)  
**Rhythm:** 1 note + 1 small exercise per day, committed here.

## Week 1–2: Excel for BI
- Day 1: Data cleaning basics — TRIM, Remove Duplicates, Text to Columns
- Day 2: Date & text formats, Find & Replace, Data Validation
- Day 3: XLOOKUP / VLOOKUP, INDEX + MATCH
- Day 4: IF, IFS, COUNTIF / SUMIF
- Day 5: PivotTables — grouping, slicers, calculated fields
- Day 6: PivotCharts + dashboard layout
- Day 7: Weekly mini-project — clean + summarise a messy sales file
- Week 2: Advanced pivots, Power Query basics, conditional formatting for insight, mini dashboard

## Week 3–4: SQL Basics
- SELECT, WHERE, ORDER BY, LIMIT
- Aggregations: COUNT, SUM, AVG, GROUP BY, HAVING
- JOINs: INNER, LEFT, RIGHT, FULL
- Subqueries & CTEs
- Window functions (intro): ROW_NUMBER, RANK
- Weekly mini-project: answer 5 business questions from a small database

## Week 5–6: Python for Data Analysis
- Python setup, Jupyter, pandas basics
- Reading CSV/Excel, head/info/describe
- Filtering, grouping, merging DataFrames
- Matplotlib basics for quick charts
- Weekly mini-project: same sales analysis as Excel/SQL, in Python — compare approaches

## Week 7–8: Data Visualisation & Storytelling
- Choosing the right chart (bar vs line vs scatter vs KPI)
- Avoiding misleading charts
- Dashboard principles: one message per chart, hierarchy, colour
- Writing insight: observation → so what → action
- Weekly mini-project: 1-page insight report with 3 charts

## Week 9–10: Digital Marketing Analytics
- Marketing funnel: awareness → consideration → conversion → retention
- GA4 basics: sessions, users, conversions, events
- SEO basics: keywords, ranking, CTR
- Campaign metrics: CPC, CPM, CTR, ROAS, CAC
- Weekly mini-project: analyse a mock campaign dataset, recommend next step

## Week 11–12: BI Concepts + Portfolio Project
- What is BI? Descriptive → diagnostic → predictive → prescriptive
- KPIs & metrics: leading vs lagging, SMART KPIs
- Dashboard design: audience, decisions, refresh
- Final mini-project: end-to-end BI case — clean data (Excel/SQL/Python) → dashboard → 1-page recommendation

## Rules
- Every entry is dated and real. No backdated commits.
- Each note ends with: What I learned + What I will try next.
